Яндекс.Карты
1. Тема и целевая аудитория
1.1 Тема
Яндекс.Карты - геосервис для построения маршрутов, входящий в экосистему Яндекс. Яндекс карты позволяют строить маршруты, смотреть расписания всех видов транспорта, оценивать загруженность дорог и многое другое. Сервис работает в России, странах СНГ и ряде других регионов.

1.2 Функционал MVP
Авторизация пользователя
Построение маршрутов на метро и личном транспорте 
Оценка загруженности дорог
Рекомендация мест для посещения

1.3 Целевая аудитория
География: Россия, Казахстан, Армения, Грузия, Узбекистан

Размер аудитории:

Месячная аудитория — 95 млн пользователей
Дневная аудитория — 20 млн пользователей
Средний возраст: 20–45 лет

Устройства: 85% — мобильные, 15% — десктоп
